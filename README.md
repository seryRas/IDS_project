# 🏥 Informační systém lékárny

Projekt zaměřený na návrh a implementaci relační databáze v prostředí
**Oracle Database 12c**.

------------------------------------------------------------------------

## 📌 O projektu

Cílem projektu je návrh a realizace relační databáze na zvolené téma v
rámci předmětu. Projekt je řešen ve dvoučlenném týmu.

Zvolené téma:

> **Informační systém lékárny**

------------------------------------------------------------------------

## 🎯 Zadání

Navrhněte databázový systém pro lékárnu, která:

-   vydává léky na předpis i bez předpisu\
-   umožňuje evidenci vydávaných léků\
-   umožňuje evidenci zdravotních pojišťoven\
-   eviduje příspěvky zdravotních pojišťoven na léky\
-   umožňuje import aktualizací příspěvků (které se mohou v čase měnit)\
-   umožňuje export výkazů pro zdravotní pojišťovny\
-   umožňuje kontrolu skladových zásob\
-   umožňuje zjistit dostupnost konkrétního léku

Léky jsou identifikovány: - číselným kódem - nebo názvem

Některé léky jsou vydávány výhradně na předpis.

------------------------------------------------------------------------

## 🗂 Struktura projektu

Projekt se skládá ze čtyř částí odevzdávaných postupně v průběhu
semestru:

1.  Konceptuální návrh (ER diagram)
2.  Logický návrh (relační schéma)
3.  Implementace databázových objektů (DDL)
4.  Datové operace a pokročilé SQL (DML, dotazy, výkazy)

------------------------------------------------------------------------

## 🛠 Technické požadavky

-   Použitý SŘBD: **Oracle Database 12c**
-   SQL skripty musí:
    -   být určeny pro Oracle 12c
    -   umožňovat opakované spuštění (DROP + CREATE nebo přepsání
        objektů)
    -   být odevzdány jako prostý text
    -   používat kódování **UTF-8**
-   Diagramová část se odevzdává jako jeden soubor ve formátu **PDF**
